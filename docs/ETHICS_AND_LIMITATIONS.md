# Ethics and Limitations

This project is educational and analytical.

It is not a production campaign allocation system.

## Misuse risks

- Targeting users with manipulative or exploitative messages.
- Excluding customers unfairly from useful offers.
- Over-contacting vulnerable customers.
- Treating uplift scores as causal truth without experiment validation.
- Using proxy variables that encode sensitive or protected attributes.

## Safe-use principles

- Keep a randomized holdout group.
- Monitor outcomes after deployment.
- Use frequency caps and consent-aware communication.
- Review segment-level impacts.
- Avoid punitive or discriminatory targeting.
- Treat the model as decision support, not as an autonomous decision-maker.
